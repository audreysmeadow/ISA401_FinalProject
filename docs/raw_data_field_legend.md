# Raw Data Field Legend

This legend describes fields found in the raw data files generated by the R acquisition scripts.

|Field         |Data_Type |Description                                                                      |Source                       |
|:-------------|:---------|:--------------------------------------------------------------------------------|:----------------------------|
|Diesel_Raw    |character |Raw diesel price string.                                                         |AAA State Gas Price Averages |
|Mid_Grade_Raw |character |Raw mid-grade gas price string.                                                  |AAA State Gas Price Averages |
|Premium_Raw   |character |Raw premium gas price string.                                                    |AAA State Gas Price Averages |
|Price_Date    |character |AAA-reported price date from the page text.                                      |AAA State Gas Price Averages |
|Raw_Table_Row |character |Raw markdown table row from the AAA state gas price table.                       |AAA State Gas Price Averages |
|Regular_Raw   |character |Raw regular gas price string.                                                    |AAA State Gas Price Averages |
|Retrieval_URL |character |Text-reader URL used to retrieve the page content when direct access is blocked. |AAA State Gas Price Averages |
|Scrape_Date   |Date      |Date the AAA page was scraped.                                                   |AAA State Gas Price Averages |
|Source_URL    |character |Original AAA state gas price averages page.                                      |AAA State Gas Price Averages |
|State         |character |State or district name in the AAA table.                                         |AAA State Gas Price Averages |
|State_Abbr    |character |Two-letter state abbreviation from the AAA state link.                           |AAA State Gas Price Averages |
